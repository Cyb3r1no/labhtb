---
description: Recover the CPTS methodology path when the operator is stuck
---

Do not run target-facing commands.

1. Read `notes.md` and identify the current PHASE.
2. Review unresolved services, credentials, footholds, routes, and recent state changes.
3. Read only the relevant section of `CPTS-MAP.md`.
4. Read only the relevant section of `CPTS-Checklists/`.
5. If `CPTS-NOTES.md` exists, search it for the familiar technique/tool/syntax relevant to the current branch.
6. Identify one meaningful branch that has not been ruled out.

Return only:

### PHASE
Current phase.

### MISSED
The one important branch/check that appears unresolved.

### NEXT
Exactly one action or command.

### WHY
Why this is the best next step now.

### EVIDENCE
What proof to preserve, if any.

Then stop and wait.
